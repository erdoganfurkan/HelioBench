## Known issues found while producing this run, not fixed here

- **`n1_mms_fgm` invented-id bug** — the detector fires and warns, but the agent loop ends instead of retrying with the real ids. Logged in HelioAI's memory: `bug-unknown-ids-no-retry-2026-08-19`.
- **Sandbox disk cost** — `_seed_speasy_inventory` copies whatever `$XDG_DATA_HOME/speasy` resolves to. On the shell used to drive this benchmark (VS Code snap), that pointed at an unrelated 611MB cache instead of the normal ~35MB one, filling the disk mid-run twice. Not a HelioAI bug — the fix (81202ea/f49c25e) works correctly; this was an environment artifact of the driving shell. Worked around by pinning `XDG_DATA_HOME` explicitly before `heliobench run`.
- **Azure daily quota (2M tokens/day)** — hit mid-sweep on the first n1 attempt (30 tasks × 3 runs). The 4 cut tasks were re-run cleanly the next day once the quota reset.
